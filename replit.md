# utk.ai — Unsloppable Tech Kickstarter AI

An elite AI venture studio & talent accelerator landing site: premium AI internships (participant-paid — interns invest, we do **not** pay them), done-for-you company building, ready-made turnkey AI platforms/websites you can buy off-the-shelf, and elite 1:1 AI coaching from the founder of GoldRock AI. Light-luxury "Liquid Crystal" design on an ocean-crystal palette (emerald/teal/aqua/sapphire).

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string
- Optional env: `TURNSTILE_SITE_KEY` + `TURNSTILE_SECRET_KEY` (Cloudflare Turnstile) — gate the AI assistant's free-form chat. In dev they're optional (Cloudflare test keys auto-pass); in production, if real keys are absent the free-form AI **fails closed** (disabled) while the canned FAQ tree keeps working.
- Production: published at `https://utk.ai` (verified custom domain; also `https://utk-ai.replit.app`). All social/SEO absolute URLs in `index.html` point to `https://utk.ai` — get the live domain from `getDeploymentInfo().primaryUrl`, never `$REPLIT_DOMAINS`.

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- AI: OpenAI via Replit AI Integrations proxy (`gpt-5-nano`)
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Architecture decisions

- Auth is Replit-managed Clerk; web uses cookie auth (same-origin `/api` via the shared proxy) — no Bearer/token getter.
- Roles (`user`/`staff`/`admin`): explicit `ADMIN_EMAILS` allowlist wins; otherwise the first-ever user bootstraps as admin. `requireStaff` gates pipeline work the owner delegates (review applications, advance status, leave notes, read/triage the contact inbox); `requireAdmin` stays reserved for role changes. The zero-admin bootstrap check + insert AND the last-admin demotion guard both run in a DB transaction guarded by the **same** Postgres advisory lock so concurrent first-signups can't double-bootstrap and concurrent demotions can't both remove the final admin.
- Orval generated only mutation hooks (`useCreateApplication`, `useUpdateApplicationStatus` — body `{status?, dealType?}`, `useCreateApplicationNote`, `useUpdateUserRole`); GET endpoints are plain async fns (`getMe`, `listMyApplications`, `listApplications`, `listApplicationNotes`, `listUsers`, `getAdminStats`) wrapped in `useQuery`. The admin UI computes pipeline counts client-side, so `getAdminStats` exists but is currently unused by the UI.
- Home stays accessible to everyone (marketing + apply site) — signed-in users are NOT force-redirected to the portal; only hard rule honored is never redirecting unauth users to sign-in.
- The apply dialog gates on auth: signed-out shows Create account / Sign in; signed-in shows a prefilled form that persists via `POST /api/applications`.
- AI assistant: only free-form typed questions hit the AI (`gpt-5-nano` via the OpenAI integration); the FAQ decision tree is canned/instant with zero AI cost. Free-form is gated by Cloudflare Turnstile → a stateless HMAC "pass" (20min, IP-bound, signed with `SESSION_SECRET`, timing-safe compare). Rate limits are DB-backed (per-IP hourly/daily + a global daily cap as the hard spend backstop) enforced under a single global Postgres advisory lock; a usage row is reserved up front and released if the AI call fails. Turnstile fails CLOSED in production when real keys are absent. Details in `.agents/memory/assistant-gating.md`.

## Product

Landing site for an elite AI venture studio (no specific city named on the site). **Everything is paid and premium**: AI internships are participant-paid (interns invest ~$4,000/mo — we do NOT pay them; it's an accelerator you pay for, not a job), 1:1 coaching is $1,500/hr, done-for-you studio builds run $5,000–$25,000+ by scope, and we also sell **ready-made turnkey AI platforms/websites** off-the-shelf that a customer can buy outright and launch in days (productized, "ask for the current catalog" pricing; turnkey card CTA routes to the contact form, not the apply dialog — it has no `ApplicationType`). Equity/hybrid deals exist only **on top of** payment — equity clients always pay too. The studio (done-for-you) card carries a "We don't just build it — we may back it." callout: the founder **may** invest his own capital into a client's company — framed as a positive (conviction / skin-in-the-game / aligned incentives / access to capital), and always **in addition to** cash, never instead of it; keep it optional/selective ("when we believe in what we've built"), never a guarantee. Visitors apply via an in-page dialog (Clerk sign-in required) or send a qualified sales lead through the contact form; submissions persist to the DB. Users track their requests in `/portal`; staff/admins review and advance them through the enrollment pipeline in `/admin`.

## User preferences

- NO purple/violet and NO orange anywhere. Brand palette is ocean crystal — emerald + teal + aqua + sapphire — on a light-luxury (pearl) background. Light mode is the default.
- Do not mention Knoxville (or any specific city) as the studio's own location/branding anywhere on the site. Exception: real portfolio project brand names and their live links may keep place names (e.g. NashvilleHackathons.com, Nashmap.com, Gulf Shores) — confirmed they should stay as-is.
- Internships are **participant-paid** — never write copy implying we pay, employ, or stipend interns ("paid internship", "earn while you build", "portfolio + income", "get paid to learn" all read backwards and are wrong). Frame them as a premium accelerator you invest in. Equity deals are always **in addition to** cash, never instead of it. See `.agents/memory/utk-business-model.md`.

## Gotchas

- Do not edit OpenAPI `info.title` — it controls generated filenames. Run codegen after spec changes.
- Turnstile test keys are used ONLY in genuine local dev, gated on `REPLIT_DEPLOYMENT !== "1"` AND `NODE_ENV !== "production"` — never rely on `NODE_ENV` alone (deployments may not set it → fail-open). Test keys pasted into prod env are rejected (treated as "not real").
- `gpt-5-nano` is a reasoning model: `max_completion_tokens` must leave headroom for reasoning + output; use `reasoning_effort` to bound cost/latency.
- `pnpm --filter @workspace/<slug> run build` needs workflow-provided `PORT`/`BASE_PATH`; verify with `typecheck` from bash instead.
