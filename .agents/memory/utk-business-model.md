# utk.ai is participant-paid, and the internship model is backwards from the norm

Every engagement is paid and premium. The part a future agent will get wrong by reflex:

- **Interns pay us (~$4,000/mo).** It's a paid accelerator you *invest in*, not a job. We do NOT pay, employ, or give a stipend/salary to interns. The whole point is the experience/skills/portfolio/résumé they buy.
- **1:1 coaching: $1,500/hr.**
- **Done-for-you studio builds: $5,000–$25,000+** by scope.
- **Equity/hybrid deals are ON TOP of payment, never instead of it** — equity clients always pay too, and pay well.

**Why:** the owner corrected this explicitly. Canonical prices/wording live in `replit.md` (Product + User preferences); this file exists because the model is counterintuitive and keeps getting violated.

**How to apply (copy trap):** never write copy that implies the intern earns money. "Paid internship", "earn while you build", "portfolio (and income)", "stipend", "get paid to learn" all read as *we pay the intern* and contradict the model — the architect caught these twice in one batch. Prefer "participant-paid", "you invest", "training internship", "portfolio-grade product/proof". When unsure, frame internships as an accelerator you pay for.

## eFormative proof point — "$1.1M" is CAPACITY, not ARR

The site's `#proof` section uses the owner's real proof point: **eformative.com was sold, built & delivered for a client in 7 days for $21,300.** From that, $21,300 × 52 ≈ **$1.1M+**, which we label **"annualized build capacity."**

- **Hard rule:** that $1.1M is a *production-rate* figure (the 7-day pace repeated weekly), NOT recurring revenue and NOT ARR. The owner themselves flagged this ("Do not call this ARR unless it's recurring"). Always keep the clarifying footnote; never relabel it "ARR" / "revenue we make" / "we earn $1.1M".
- **Why:** calling a one-off services capacity number "ARR" is a materially false financial claim — the same class of honesty trap as the Guardian co-billing.
- The owner's brainstorm doc also proposed repositioning utk.ai into a "GoldRock student/recruiting funnel" with a new hero. That was **deliberately NOT done** — it conflicts with the established utk.ai venture-studio brand. Only revisit on an explicit request.
