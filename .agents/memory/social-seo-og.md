---
name: Social/SEO + OG image + favicons for a static Vite artifact on Replit
description: How to build link-preview images, favicons, and meta tags for a static web artifact, plus the Replit platform gotchas.
---

- **Replit's react-vite scaffold ships broken SEO defaults.** `index.html` has placeholder og/twitter descriptions ("Update this description…") and a default `favicon.svg` that is a SOLID ORANGE square (`#FF3C00`). Always replace both — the orange favicon silently violates any brand with a no-orange rule and is the classic "Replit messed up my favicon" complaint.
- **Absolute URLs are mandatory** for `og:image`, `og:url`, `twitter:image`, `canonical`, and JSON-LD. A static Vite deploy bakes these into `index.html` at build time (no server to inject the host), so use the REAL production domain from `getDeploymentInfo().primaryUrl` — NOT `$REPLIT_DOMAINS`, which inside the dev container is the `.replit.dev` dev domain. (This project's primaryUrl is a verified custom domain.)
- **OG social card (1200×630):** don't use AI image generation (it mangles text) and don't rely on system fonts (brand fonts aren't installed system-wide). Instead build a self-contained HTML card (inline CSS + Google Fonts `<link>`) sized exactly 1200×630 in `public/`, then capture it with the **app_preview screenshot tool at viewport [1200,630]** so it renders with the real web fonts. Save → resize/optimize to `public/opengraph.jpg` → delete the temp card HTML so it isn't deployed.
- **Favicons without rsvg/sharp/inkscape:** only ImageMagick (`magick`) is available, and it rasterizes simple brand SVGs fine. `magick -background none -density 768 favicon.svg -resize NxN -depth 8 -strip out.png` for each size; multi-size ICO via `magick 16.png 32.png 48.png favicon.ico`. Make `apple-touch-icon.png` a **full-bleed gradient square** (no transparent rounded corners) so iOS applies its own mask cleanly; the in-browser `favicon.svg` keeps rounded corners.
- **The actual `og:image` file dimensions MUST match the declared `og:image:width`/`og:image:height`.** If the meta says 1200×630 but you ship a 1280×720 (or any other aspect ratio) file, many link-preview/social tools letterbox or pad it with GRAY bars — it reads as a "dull gray, no real image" card. Capture/resize to EXACTLY 1200×630 (`magick … -resize 1200x630^ -gravity center -extent 1200x630`) and confirm with `identify` before shipping. A purpose-built typographic card (logo + tagline) reads far better as a social preview than a shrunk full-page screenshot.
- **Verify the production output**, don't trust dev serving alone: `PORT=18561 BASE_PATH=/ pnpm --filter @workspace/utk-ai run build`, then grep `dist/public/index.html` for the meta and `ls dist/public` for the assets. Vite copies everything in `public/` to `dist/public` root.
